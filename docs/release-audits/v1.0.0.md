# Release audit — v1.0.0

The evidence behind [the v1.0.0 release note](https://github.com/castlemountsendemails/plx-native/blob/v1.0.0/docs/release-notes/v1.0.0.md). This is a private build from a fork, built by GitHub Actions from the tag `v1.0.0`. The release workflow keeps the webOS package and the release-signed Fire TV APK as run artifacts and publishes nothing. The section at the bottom is filled only by a run that publishes, so it stays a placeholder.

## External compatibility reports known at release time

None. No one other than the owner has run this build.

## Compatibility tiers, and what moved

The three sticks and the LG above are in the verified tier for the debug build of the same code. Every other webOS firmware from 4.0 up is in the starts-and-nothing-further tier, graded only by the firmware check in CI. A static check does not move a playback line.

## Known issues at release, with provenance

- The Stick 4K's Appstore deletes a sideloaded app's tile on each update. Measured on the Stick 4K; the install steps send a broadcast that redraws it.
- Dolby Vision and other hardware-specific extras were not checked.
- The LG's Home-and-return behavior and the paused-decoder screensaver are unchanged from 0.9.0.

## Release configuration

| | |
|---|---|
| webOS flavour | `com.beb.plxnative` (stable), `RELEASE=1`, which drops `devtools` and `devtriggers` |
| Fire TV | `com.beb.plxnative`, versionCode 10000, release-signed, built with `--no-default-features` |
| built by | GitHub Actions on the fork, `release.yml` on the tag `v1.0.0` |
| toolchain | webOS NDK and Android NDK 27.3.13750724, Rust as pinned by `rust-modules/rust-toolchain.toml` |

Telemetry: the LG package carries the repository variables `PLX_SENTRY_DSN` and `PLX_POSTHOG_KEY`, which hold placeholder values (an unresolvable Sentry host and a junk PostHog key), and the consent flags default to false, so nothing can be sent. The Fire TV build sets all four telemetry variables empty, and the release job fails if `libmain.so` carries the placeholder host or key.
