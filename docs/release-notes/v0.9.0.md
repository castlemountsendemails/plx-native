# v0.9.0 — a nav rail down the left edge, in a private build

This is a private build for one household, not a public release: it is the 0.8.0 app with a navigation rail down the left edge in place of the tab strip, built from a fork. Nothing here has been published or offered through the Homebrew Channel.

## What's new

- **A nav rail on the left edge.** Home, Search, Watchlist, one item per favorite library, a More item and Profile sit in a column that widens with labels while it has focus. Left from a page's left edge enters it and Right returns to where you were.
- **More lists every library, grouped by server.** OK opens a library whether or not it is a favorite, and a star at the right of each row adds or removes it from the favorites. A library on a server that is offline or has stopped sharing with you is dimmed and says why.
- **Favorites keep an order.** Hold OK on a favorite in the rail, move it with Up and Down, and press OK to save or Back to cancel. A hint explains the gesture once.
- **Home shows Continue Watching only.** The top tab strip, the profile chip and Home's banner and discovery shelves are gone; an empty Continue Watching says "Nothing in progress" and points at the rail.
- **Back closes the app on televisions that cannot show their launcher.** It asks before leaving, and on webOS 4.4 it no longer does nothing.

## Fixed

- **A rail with many favorite libraries piled its items on top of each other.** The library list now scrolls while Home, Search, Watchlist and Profile stay put.
- **A library deleted on its server lingered in the rail** until the app restarted. It now drops out the next time the server's library list is read.

## Compatibility

- **Plays video, verified by watching it — one 2018 LG set.** An LG 75UK6570AUA reporting webOS 4.4. The rail build ran there under the debug app id; the stable package in this release had not been installed on it when this note was written.
- **Starts, and nothing further is known — every other firmware from webOS 4.0 up.** This binary's libraries and symbols are checked against the firmware images webosbrew has; the result for this build is in the [technical audit](https://github.com/castlemountsendemails/plx-native/blob/prod-0.9.0/docs/release-audits/v0.9.0.md).

## Known issues

- **A favorite shows only once its server has answered the first time in a run,** unless its name was saved earlier, in which case it is drawn from the saved name and dimmed until the server is found.
- **The Watchlist pulse is upstream's white 0.4 second flash.**
- **Two paths were never exercised on a television:** a server that refuses this account's access, and a library deleted on its server.

## Installing

Download **com.beb.plxnative_0.9.0_arm.ipk** and install it with [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop) or `ares-install`. You do **not** need a rooted TV. It has the same app id as 0.8.0 and replaces it in place.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file built here:

```
__IPK_SHA256__  com.beb.plxnative_0.9.0_arm.ipk
```

Crash and analytics reporting are compiled in with placeholder credentials that cannot deliver anything. Exactly what was built and checked is in the [technical audit for v0.9.0](https://github.com/castlemountsendemails/plx-native/blob/prod-0.9.0/docs/release-audits/v0.9.0.md).
