# v1.1.0 — Watchlist for more titles, delete and scan from the app, and a reworked side menu

This is a private build for one household, not a public release: it is the 1.0.0 app plus five additions, built from a fork. Nothing here has been published or offered through the Homebrew Channel.

## What's new

- **The Watchlist works for older library titles.** Movies and shows the server matched with an older agent (an IMDb, TMDB or TVDB id rather than a Plex one) now show the Watchlist disc and the Add and Remove menu row, as other titles do. Titles with no outside id at all (a local match) still have none.
- **Delete from the app.** A movie's or show's card menu ends with a Delete row when the server allows deleting. It asks for confirmation, with Cancel selected first, and removes the whole item from the server and its disk. On a TV running webOS 4.4 the "Deleted" toast is refused by the system, so no message shows there.
- **Scan a library.** The Library page's header ends with a "Scan library" button on a server you own. It asks the server to scan that one library and says "Scan requested". An open library re-reads itself when the server reports a title added or removed.
- **Profile is at the top of the side menu.** The Profile circle is now the first item, above Home, and opens the account menu.
- **A held Up on the side menu jumps to Home.** A tap still steps one stop.

## Compatibility

- **Fire TV, release build: not yet verified on a stick when this note was written.** The same code, built as a debug app, passed the owner's check of every addition on a Stick 4K, a Stick HD and a Stick 3rd generation. The release build installs under its own app id, `com.beb.plxnative`.
- **LG webOS 4.4: the same debug-app check passed on an LG 75UK6570AUA.** The 1.1.0 package had not been installed on it when this note was written.
- **Starts, and nothing further is known — every other firmware from webOS 4.0 up.** The binary's libraries and symbols are checked against the firmware images webosbrew has; the result for this build is in the [technical audit](https://github.com/castlemountsendemails/plx-native/blob/v1.1.0/docs/release-audits/v1.1.0.md).

## Known issues

- **The Fire TV app is sideload-only** and is not in the Amazon Appstore. On the Stick 4K, each update removes the app's tile until the Appstore is told to redraw it; the install steps do that.
- **Delete removes the whole item**, every version of it; deleting one version is not offered.
- **A library removed on the server stays in the app until it is relaunched.**
- **Dolby Vision and other hardware-specific extras were not part of this release's checks.**
- **Two LG leftovers remain:** the Home-and-return behavior and the paused-decoder screensaver.

## Installing

Download **com.beb.plxnative_1.1.0_arm.ipk** for an LG television and install it with [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop) or `ares-install`. You do **not** need a rooted TV. It has the same app id as 1.0.0 and replaces it in place. The Fire TV APK is installed with `adb install -r`.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file built here:

```
__IPK_SHA256__  com.beb.plxnative_1.1.0_arm.ipk
```

Crash and analytics reporting are compiled into the LG package with placeholder credentials that cannot deliver anything, and are absent from the Fire TV app. Exactly what was built and checked is in the [technical audit for v1.1.0](https://github.com/castlemountsendemails/plx-native/blob/v1.1.0/docs/release-audits/v1.1.0.md).
