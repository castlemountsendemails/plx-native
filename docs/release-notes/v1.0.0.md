# v1.0.0 — PlxNative on Fire TV sticks, in a private build

This is a private build for one household, not a public release: it is the 0.9.0 app plus a Fire TV port and a reworked search page, built from a fork. Nothing here has been published or offered through the Homebrew Channel.

## What's new

- **A Fire TV app.** The same app now runs on Fire TV sticks as a sideloaded APK, with the same rail, libraries, search, watchlist and playback. It is built for the Fire TV Stick 4K (1st generation), the Fire TV Stick 3rd generation and the Fire TV Stick HD (1st generation).
- **The empty search page looks like stock Plex's.** The search box is a thin outlined box that reads "Search", recent searches are one row of up to four chips ending in "Clear Search History", and "You can search titles, people, collections and more…" sits under them. This applies on the LG as well.
- **The side menu's Search always starts a fresh search.** Pressing it, from the search page or from another page, opens an empty field with the recent searches; Back from a result keeps that result's query.
- **On Fire TV, Back at the top level asks before leaving.** Exit closes the app completely so the next launch starts fresh; Home leaves it running in the background.

## Fixed

- **The Fire TV keyboard's text box stayed empty while typing in search.** It now shows what is in the search field.
- **Back in search brought the Fire TV keyboard straight back up.** Back now closes it and leaves it closed.

## Compatibility

- **Fire TV, release build: not yet verified on a stick when this note was written.** The same code, built as a debug app, passed the owner's check on a Stick 4K, a Stick HD and a Stick 3rd generation. The release build installs under its own app id, `com.beb.plxnative`.
- **LG webOS 4.4: the 0.9.0 production build runs on an LG 75UK6570AUA.** The 1.0.0 package had not been installed on it when this note was written.
- **Starts, and nothing further is known — every other firmware from webOS 4.0 up.** The binary's libraries and symbols are checked against the firmware images webosbrew has; the result for this build is in the [technical audit](https://github.com/castlemountsendemails/plx-native/blob/v1.0.0/docs/release-audits/v1.0.0.md).

## Known issues

- **The Fire TV app is sideload-only** and is not in the Amazon Appstore. On the Stick 4K, each update removes the app's tile until the Appstore is told to redraw it; the install steps do that.
- **Dolby Vision and other hardware-specific extras were not part of this release's checks.**
- **Two LG leftovers remain:** the Home-and-return behavior and the paused-decoder screensaver.

## Installing

Download **com.beb.plxnative_1.0.0_arm.ipk** for an LG television and install it with [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop) or `ares-install`. You do **not** need a rooted TV. It has the same app id as 0.9.0 and replaces it in place. The Fire TV APK is installed with `adb install -r`.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file built here:

```
__IPK_SHA256__  com.beb.plxnative_1.0.0_arm.ipk
```

Crash and analytics reporting are compiled into the LG package with placeholder credentials that cannot deliver anything, and are absent from the Fire TV app. Exactly what was built and checked is in the [technical audit for v1.0.0](https://github.com/castlemountsendemails/plx-native/blob/v1.0.0/docs/release-audits/v1.0.0.md).
